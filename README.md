## 📖 Tentang Proyek

Website ini mencakup **katalog produk**, **program kemitraan bisnis**, **promo kartu kredit**, dan **pusat layanan pelanggan**, dibangun sebagai multi-page website yang ringan dan responsif.

## ✨ Fitur Utama

| | Halaman | Fitur |
|---|---|---|
| 🏠 | **Beranda** | Hero slider banner produk unggulan, informasi singkat dan tagline toko |
| 🛍️ | **Katalog Produk** | Filter kategori (**Squishy Food**, **Squishy Animal**, **Best Seller**), badge **Hot Deal** / **New** / **Limited**, modal detail produk, tombol **Buy Now** |
| 🤝 | **Mitra Bisnis** | Keuntungan menjadi mitra, daftar mitra terpercaya beserta testimoni, form bergabung |
| 💳 | **Kartu Kredit** | Cashback dari DBS, BRI, OCBC NISP, Bank Mayapada; cicilan 0% BCA, Mandiri, BNI, Citibank; form pengajuan |
| 🎧 | **Service Center** | Lacak pengiriman, kebijakan retur 7 hari, dukungan Telepon / WhatsApp / Email, FAQ lengkap, form pesan ke CS |
| 📞 | **Contact Us** | Informasi kontak toko, lokasi Bandung, Indonesia |

## 📁 Struktur Halaman

```
├── index.html          # Beranda
├── profile.html        # Profil perusahaan & tim
├── products.html       # Katalog produk dengan filter
├── mitra.html          # Program kemitraan bisnis
├── kreditproduk.html   # Promo & cicilan kartu kredit
├── servicecenter.html  # Pusat layanan pelanggan & FAQ
└── contact.html        # Kontak kami
```

## 🚀 Cara Menjalankan Proyek

**1. Clone repository ini**

```bash
git clone https://github.com/Luxuoka/NAMA_REPO.git
cd NAMA_REPO
```

**2. Buka di browser**

Tidak memerlukan build tool, cukup buka `index.html`. Untuk development yang lebih nyaman, gunakan ekstensi **Live Server** di VS Code.
